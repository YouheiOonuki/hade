# hade — ド派手版（計算はまじめ、演出だけ派手）

公開 URL: **https://yorozu-craft.com/hade/**。要件は yorozu-plans の ROADMAP 7.39.1（K170、D300・D303）、設計は企画書 `docs/86_ド派手版.md`。

税や制度の計算の結果を、偽エラー・再起動・スロット・号外などの演出つきで出す別館。**計算と出典はまじめな版の `lib` を同じ URL（`/seido-keisan/lib/*.js`）で読む**ので、数字はまじめな版と必ず同じ（写しを持たない）。まじめな版のページは変えず、そこからは 1 行のリンクだけ。

## しくみ

| ファイル | 役目 |
|---|---|
| `engine.js` | 演出エンジン。台本の場面を順に再生し、最後に「決め」の画面。場面の型は confirm（3 段の確認）・fakeError・reboot・drumroll・slot・gougai・cm・finale |
| `scripts/<道具>.json` | 台本（結果の種類ごとの場面の列と文）。`engine.js` の `validate` が型・長さ・点滅・人を動かす偽の警告の語を確かめる |
| `<道具>/index.html`・`app.js` | 入力の欄 → まじめな版の `calc` → 結果の種類で台本を選ぶ → 決めの画面（見出し・数字・ツッコミ・出典・共有・まじめな版で確かめる・もう一回） |
| `tests/hade.test.js` | 台本・点滅・数字がまじめな版と同じ・禁止の挙動が無い・共有の URL に値が無い・ページの決まり |

## 守ること（D303）

- 「※演出です」を常に出す。OS やブラウザの本物の画面と見分けがつかないほど真似ない。偽の警告で人を動かさない（「今すぐ」などの誘導をしない）
- 本物の `window.open`・履歴の書き換え・閉じる確認・止まらない繰り返しを使わない（崩壊も窓もページの中の見せかけ）
- 音は押してから（既定は無音）。点滅は 1 秒に 3 回まで。「視差効果を減らす」の設定なら決めの画面だけ。「飛ばす」を常に出す
- 広告なし（偽の警告の演出は AdSense の規約に触れる）。英語版なし（笑いは訳せない）。`noindex` にしない（sitemap の優先度は低く）
- 入力はどこにも送らない・保存しない。共有の画像は端末の canvas で作り、金額は既定でぼかす（「3万円台」）。URL に値を入れない（`?from=share-<道具>` で測るだけ）

## テスト
