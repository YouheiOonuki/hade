# hade — 5000兆円欲しい館（中身はまじめ、発表だけ大げさ）

公開 URL: **https://yorozu-craft.com/hade/**。要件は yorozu-plans の ROADMAP 7.46（D312〜D316）、設計は企画書 `docs/89_5000兆円欲しい館ルーレット.md`（台本の書き方の決まりもそこ）。館の名前はオーナーが選んだ（2026-10-11。企画書 89 の 4 章の 3 案とは別にオーナーが決めた）。

集まりの道具（ルーレットなど）の結果を、ドラムロール・号外・紙吹雪で大げさに発表する別館。**抽選の部品はまじめな版のものを同じ URL で読む**（`/web-roulette/pick.js`）ので、当たりの決め方はまじめな版と必ず同じ（写しを持たない）。まじめな版のページは変えず、そこからは 1 行のリンク（「派手に回す」）だけ。

税・制度の計算機はここで扱わない（D313。年末調整のド派手版は 2026-10-11 に消し、`/hade/nenmatsu/` は root の `_redirects` で `/hade/` へ 301）。

## しくみ

| ファイル | 役目 |
|---|---|
| `engine.js` | 演出エンジン。台本の場面を順に再生し、最後に「決め」の画面。場面の型は drumroll（ため。`roll` で候補の名前を回す）・slot・gougai・cm・finale。`validate` が型・場面の数（3 つまで）・ため（3 秒まで）・決めの一言（20 字まで）・点滅・偽の警告の語を確かめる |
| `scripts/<道具>.json` | 台本（1 道具 3 本まで。回すたびにランダムに 1 本） |
| `<道具>/index.html`・`app.js` | 入力の欄 → まじめな版の lib → 台本を選ぶ → 決めの画面（大写しの当たり・一言・サイト名・もう一回・共有） |
| `ng-words.json` | 台本に入れない語（分類つき）。テストが突き合わせる |
| `tests/hade.test.js` | 台本の決まり・禁止語・当たりがまじめな版と同じ・禁止の挙動・共有の画像・ページの決まり |

## 守ること（D303・D311・D312・D313）

- 「※演出です」を常に出す。偽のエラー・警告・再起動・確認の画面を作らない（D313）。人を動かす語（「今すぐ」など）を使わない
- 本物の `window.open`・履歴の書き換え・閉じる確認・止まらない繰り返しを使わない
- 音は押してから（既定は無音）。点滅は 1 秒に 3 回まで。「視差効果を減らす」の設定なら黙って決めの画面だけ（紙吹雪も出さない）。「飛ばす」は小さな × を常に出す
- **説明の文は出さない**（D324）。ページに残すのは「※演出です」の小さな札 1 つと、フッターの「まじめな版」のリンクだけ。上の線は文でなく動きで守る。**例外は 1 つ（D384、2026-10-20）**: 1 画面目の下・脚の上に「この館について」（JS 無しで 100 字以上、まじめな版へのリンク）を 1 つ置く。1 画面目は変えない
- 広告なし（演出のページは本文が少なく、収益の場にしない）。英語版なし（笑いは訳せない）
- sitemap に入れ、`noindex` にしない（優先度 0.3）。**AdSense の結果が出るまではトップと pages.json に載せない**（ROADMAP 7.46.1。root の check-site の `NOT_ON_TOP`）
- 規約の線（D311）: 入力欄やログインの偽装をしない（演出は入力欄を作らない）。Cloudflare・他社・銀行・役所のロゴや名前を出さない。workers.dev などの名前に紛らわしい語を使わない
- 入力はどこにも送らない・保存しない。共有の画像は端末の canvas で作り、利用者が入れた名前は既定で入れない（選んだときだけ）。URL に値を入れない（`?from=share-<道具>` で測るだけ）
